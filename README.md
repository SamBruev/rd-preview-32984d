# Red Deck — превью сайта

Черновая публикация для показа: смотреть можно всем, в поиск не попадает
(закрыто и `noindex`, и `robots.txt`).

Адрес после публикации: https://sambruev.github.io/rd-preview-32984d/

## Как обновить превью

1. Собрать свежую версию (из папки `site-2026-08`):

   ```
   RD_SITE="https://sambruev.github.io/rd-preview-32984d" \
   RD_BASE="/rd-preview-32984d" \
   RD_PREVIEW=1 \
   RD_OUT="../RED-DECK-SITE-GITHUB" \
   python3 build-static.py
   ```

2. Двойной щелчок по `ОТПРАВИТЬ-НА-GITHUB.command` — скрипт сам
   создаст коммит, отправит на GitHub и включит Pages. При первом
   запуске попросит войти в GitHub через браузер.

## Что внутри

Шестнадцать готовых страниц (`/`, `/parks/...`, `/coaches`, `/prices`
и т. д.), каждая — обычный HTML со своим заголовком: открывается
по прямой ссылке и работает даже с выключенным JavaScript.
`404.html` ловит опечатки в адресе. Пути собраны под подпапку
`/rd-preview-32984d/` — на другом домене пересобрать с другими
`RD_SITE`/`RD_BASE`.

Боевая сборка под будущий домен делается тем же скриптом без
переменных: `python3 build-static.py` → папка `dist/`, индексация
там открыта.
